HOW TO USE THIS FOLDER
1. Clone your repo:  git clone https://github.com/Ramyasai07/laptop-sales-analysis.git
2. Checkout develop: git checkout develop   (create it first if needed: git checkout -b develop)
3. Copy EVERYTHING from this folder (including the hidden .github folder, .flake8, .dockerignore)
   into the cloned repo folder. Do not overwrite your README.md / LICENSE / .gitignore.
4. git add .  ->  git commit -m "feat: add flask app, tests, CI workflow and Dockerfile"  ->  git push
5. Open the Actions tab and wait for the green CI run.
Then continue from Step 3 of the Step-by-Step Guide.
(Delete this README_UPLOAD.txt before committing.)
